## What we did

After the clipboard, the next slice was saving a sketch. It started as a private list of JSON files in the user-data directory, recorded in [the snapshots audit](../audits/2026-10-13T02-16-53Z-snapshots.md). The owner then asked for a save system like a production drawing app: a `.smx` file they choose, Save As, Save a Copy, Open, recent files, and a local recovery copy that does not overwrite the file. That work is in [the smx audit](../audits/2026-10-13T14-36-28Z-smx-save.md). Session tests round-tripped a `.smx`. The file dialog was not opened in a window check. The owner reviewed the save system on 2026-10-13. Save As is Ctrl+Shift+S. A changed sketch shows a dot in place of the tab's close mark, and an asterisk before the name in the window title. A failed save or open shows the file and the reason. Those changes are in `b11a89a`.

The owner confirmed that the app works with the XP-Pen tablet. The device check had been open since [the pressure audit](../audits/2026-10-10T15-48-17Z-wayland-pen-pressure.md), which had run the app on their Wayland session and left the pen itself untried.

## What we learned

The version number was never defined. The pitch's first version is a boundary around the product. The pipeline stores a version only when one is agreed, and it does not ask for that number when a project starts from nothing. The owner wants version 1.0 to be the goal in that case, meaning the full realization of the pitch, with this version's documents kept under a `v1.0` folder.

## Where things stand

The owner has confirmed the XP-Pen. Save, open, and recovery are on local `dev` and have not been pushed. A saved drawing has not been opened again in a recorded window check. No release version had been agreed before this conversation.

## Next steps

Agreed, and not yet done: treat version 1.0 as the goal for a project that starts from nothing, move this project's documents, including the pitch, under `v1.0`, write a post-mortem skill and `post-mortem.md` when that version is closed, then commit, push `dev`, and merge with `main`.
