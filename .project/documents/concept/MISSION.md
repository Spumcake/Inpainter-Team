# Inpainter — mission

Inpainter offers a human-directed, AI-native animation pipeline. Its key loop starts with a brief: the person describes what they want, and the agent turns it into a video. Unlike tools that go straight from the request to the output, Inpainter stops between them. The work moves through staged intermediates the person can see and change, so their intent is preserved before the final rendering pass.

Animation is where Inpainter starts, not where it ends. Its open-ended design invites extensions beyond that use.

Inpainter is two things that work together:

- **The software** is open source: desktop software where the person and the assistant shape the intermediates together. It works fully without the platform, with the person's own generation endpoints, such as OpenAI, fal.ai, or ComfyUI.
- **The platform** is closed: a video and image generation service that renders the intermediates, and the commercial side of Inpainter. It runs its own ComfyUI instance and comes with skills that work only with it.
