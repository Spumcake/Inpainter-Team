## Attempts and result

Save writes `sketch-{id}.json` beside the preferences file, format version 1, with the id, saved name, camera, and the object tree. It does not store history, selection, the clipboard, tool settings, or the panel. A second save overwrites that id and clears the dirty flag. Open lists saved names in ascending id order. A row is the saved name only. Choosing one adds a tab, or focuses the tab when that sketch is already open. With nothing saved, Open stays light.

The four points the documents left open were built from readings: an opened sketch has no selection and no highlighted canvas; an unreadable file is skipped, does not stop the app, and keeps its id; a failed write leaves the sketch dirty with no new dialog; two rows may show the same name.

Review found two defects. Save could clear dirty while typed words were still a draft, so quit would drop them without asking. An unreadable `sketch-4.json` did not reserve id 4, so a later save could replace it. Both were fixed. Review also noted that the open list rereads every snapshot on each frame, and that undo after a save leaves the sketch dirty. The reread was left as it is. The dirty flag after undo was left as it is.

The window check sent keys only to the Simple Sketch window. Ctrl+S wrote `sketch-1.json` for empty Untitled 1. Ctrl+O showed that name. The row could not be chosen with a key, and a drag was not used. The sketch was not opened again.
