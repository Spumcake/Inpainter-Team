## Attempts and result

Save As writes a `.smx` the person chooses. Ctrl+S then writes that path. Save As moves later saves. Save a Copy writes another file and leaves the path. Open is a file dialog. The last 10 paths are in the sketch menu. A path that is already open is focused. A path given to the program opens as the window's sketch. The tab shows the file name without `.smx`.

Every 10 minutes a dirty sketch writes `recovery/<id>.json` next to preferences. The `.smx` is not touched. A panic writes that file once more. The next launch offers recoveries one at a time, with Restore and Discard. Restore opens the copy still unsaved. Discard deletes it.

The points the documents left open were built from readings: `rfd` 0.15.4 through the desktop portal; no shortcuts for Save As, Save a Copy, or recovery; one recovery file per sketch; the last 10 paths; Save As starts in the last folder chosen, otherwise home; the file name is the tab title; existing `sketch-N.json` files are left in place.

Review found five defects: the first view marked a sketch dirty and could replace a saved camera; that dirty sketch could overwrite a recovery file still being offered; restoring an open path added a second tab; words still being typed were dropped from recovery and from quit; a failed recovery write skipped the next interval. All five were fixed.

The window check opened Simple Sketch and sent no keys, because Save and Open would have opened a portal dialog outside that window. Nothing was saved.
