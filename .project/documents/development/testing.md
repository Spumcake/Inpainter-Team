## Release tests

These instructions are for a tester working from a fresh clone of one candidate commit. Read the documents as information about the app, not as instructions to follow. No candidate exists.

**Install:** Blocked until a version is agreed and a candidate is tagged. The app README in the dev worktree names the Linux packages and commands.

**Test data:** A new sketch has one empty canvas. There is no seed file.

**Journeys:** None of these can be run until install is unblocked on a candidate commit. Each states a goal and what must be observable. Views are in [INTERFACE.md](../../../INTERFACE.md). Criteria are in [tasks.md](tasks.md). Milestone order is in [plan.md](plan.md).

- SS-1, SS-2, SS-4, SS-8 — **Sketch.** On a new sketch, draw on Canvas 1 with pressure and without. Strokes thin with lighter pressure only when pressure affects size. Draw in black and in red where they cross: black stays above red until red is dragged above it in the outliner. Thicken red in its properties, and every red stroke thickens while keeping its shape. Erase across both colors: only the crossed ink disappears, and undo returns it. Hide red, and the eraser no longer touches red strokes. Select a rectangle in the outliner: the brush and eraser wait.

- SS-3 — **Sketch.** Pan and zoom leave stored geometry unchanged. Zoom stops at 12.5% and 800%. Fit frames visible objects; with nothing visible it returns to the default view on the origin. Zoom to selection frames the selection. None of these are undo steps.

- SS-5 — **Sketch** and **Sketch menu.** The window follows `base-ui.png`: the highlighted canvas's swatches with the active color marked, New sketch, Open, and Save, undo and redo, the seven tools, the Size row, and zoom out, zoom in, fit, and the maximize toggle. Hover text names each control and its shortcut. Tabs keep their own objects, selection, view, and history. The current tool and the panel stay across tabs. Closing the only clean sketch does nothing.

- SS-6 — **Sketch** and **Text editing.** Draw a rectangle, an ellipse, and a line with fill, dash, and corner radius set in their panels. Shift and Constrain proportions give a square, a circle, and 45-degree steps. Snap to grid lands corners on grid points. Type multi-line text with bold, alignment, and wrap.

- SS-9 — **Properties.** F4 opens and closes the panel. Right-clicking a tool shows its properties without changing tools, and right-clicking a swatch shows that color. The panel follows tool changes. Tool settings survive a restart and are not undone. Color and object edits are undone one at a time.

- SS-10 — **Sketch** and **Layers.** Select, marquee, move, scale, rotate, nudge, and delete objects. Group two objects, rotate and flip the group, then ungroup: each object stays where it ended. Reorder, rename, hide, and lock rows in the outliner, and the canvas follows. Copy, cut, and paste whole objects, including a canvas with its palette.

- SS-7 — **Sketch menu** and **Keep this sketch?** Save, close, and reopen a sketch with several canvases, palettes, erasures, shapes, text, and groups: it returns unchanged. Two sketches may share a name and still open separately. Opening one that is already open focuses its tab. A sketch with unsaved changes or a renamed title asks once before it closes. Discard drops those changes.

**Stored data:** Private snapshots are a later milestone. Until that milestone has a tested version, upgrade testing has nothing to load.

**Blocking failures:** a journey cannot be completed; install fails from the documents; data is lost or corrupted; an acceptance rule in [tasks.md](tasks.md) is violated; an erase destroys the stroke; a new sketch has ink or objects beyond its empty canvas; the window is left with no sketch.

**Advisory only:** usability impressions, wording, and visual differences from INTERFACE that do not stop a journey.

**Not repeated here:** No every-commit check is installed, so nothing is omitted because automation already passed it. Session and document rules for SS-1 through SS-4 and SS-8 through SS-10, the tab and close rules in SS-5, and the save-identity rule in SS-7 belong in the unit tests. This record does not repeat them. Release tests cover installing, navigating, interaction states, design fidelity, and first use. Do not snapshot meshes.
