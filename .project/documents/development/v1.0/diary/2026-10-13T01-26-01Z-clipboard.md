## What we learned

The session tests call the copy command directly, so they passed while the keys never arrived. egui turns Ctrl+C, Ctrl+X, and Ctrl+V into copy, cut, and paste events and drops the key-down. The shortcut check only looked for a key-down, which is how Ctrl+Z works. Paste is omitted entirely when the operating-system clipboard is empty. The frame now runs the in-app command from those events, and from the key-up when the press never comes. Text from the operating-system clipboard is ignored.

Five points the documents left open were built as readings, not as owner decisions: an empty paste does nothing; a selected child of a selected group is copied once inside the group; a locked object can be copied and is not deleted by cut; undo of a cut leaves the clipboard full; the object clipboard does not run while text is being edited. Undo of a paste does not rewind the repeat offset. A mixed cut copies only the objects it can delete.
